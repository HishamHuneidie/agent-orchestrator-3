# contracts/

Directorio reservado para contratos ad-hoc que no encajan en `schemas/` (contratos versionados de artefactos estándar) ni en `templates/` (plantillas rellenables). Actualmente vacío — no forma parte del flujo activo `$feat`/`$task`.

Si en el futuro se necesita un contrato puntual entre dos agentes o integraciones que no deba vivir en `schemas/`, este es el lugar indicado.
